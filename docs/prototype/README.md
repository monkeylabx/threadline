# Threadline 产品原型

## 唯一入口

- `index.html`：唯一的可交互产品原型入口。

宽度大于 `720px` 时进入完整桌面/Web 产品；窄视口自动进入 `mobile/` 内部渲染器。不要直接分发内部页面，也不要再创建产品画板、Figma 生成器或第二套视觉稿入口。

修改规则：直接更新 HTML 与交互，并在桌面和移动视口完成验证。HTML 原型是唯一评审与交付版本，不再生成或维护 Figma 快照。

## 页面

### 当前已确认：V34 两栏布局（2026-10-17）

用户已确认 V34 替代 V33 作为桌面产品设计基线。仓库根目录执行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs/prototype
```

打开[默认演示](http://127.0.0.1:4173/)。桌面根入口和 `?screen=channel` 默认进入 V34；窄视口自动进入移动端。内嵌窗口较窄时可打开[强制桌面演示](http://127.0.0.1:4173/?viewport=desktop)。

- 企业切换、消息/工作/待办、上下文列表和个人菜单合到一个侧栏；默认 240px，支持 208–320px 拖动与键盘调节。
- 默认展示频道。私人工作独立，通过侧栏顶部切换访问；顶部搜索继续可用。
- 从频道“查看审批”或待办项打开右侧详情。关闭、Escape、点击遮罩可返回原处，焦点回到触发入口。
- 批准/拒绝、确认成果和待办数量仅为内存中的模拟状态，刷新重置。不会访问文件、执行命令或自动发布私人内容。
- 当前 A 视图隐藏历史方案切换浮条，避免遮挡输入框；B/C 历史探索仍可通过 URL 访问。
- V34 确认覆盖桌面布局和演示流程；移动端同等交互、真机和完整无障碍需独立验收。

默认入口回归检查：`node --test docs/prototype/entry-route.test.mjs`。

### 当前已确认：macOS 顶部、配色与图标导航（2026-10-23）

用户已确认提交本版原型：顶部只保留红黄绿窗口控制与搜索，采用单行 52px 顶部、居中搜索；频道名放在会话区标题中。侧栏保留宽度调整，消息/工作/待办通过侧栏切换。

配色参考[飞书官方消息产品图](https://www.feishu.cn/product/messenger)的灰白分区与蓝色强调，采用中性浅灰侧栏、白色会话区和蓝色选中态。消息/工作/待办只显示图标，使用独立 40px 圆角按钮；保留悬停提示、无障碍名称和未读提示。频道行采用 12px 圆角。颜色数值由本原型定义，并非飞书官方 Token 的逐项复制。

[已确认版本截图](screenshots/v34/feishu-icon-navigation-preview.jpg)。本次确认覆盖上述原型视觉调整；共享设计 Token 和 Desktop 尚未同步。HTML 中的红黄绿仅示意原生窗口控制位置，Desktop 落地时使用系统按钮与窗口拖动行为。生产实现和完整无障碍验收仍需独立验证。

### 区域分组修订（2026-10-23）

根据用户对桌面实机的反馈，大区域通过不同底色、留白与圆角区分。窗口顶部和侧栏共用浅灰背景，会话区成为一整块白色圆角面板；移除顶部、侧栏、会话标题和个人区域的分割线。输入区使用浅灰底，聚焦时保留清晰轮廓。顶部控件、图标导航、频道标题位置和消息行为不变。此为 #385 的原型修订，Desktop 随后同步，不代表整个产品验收通过。[本版截图](screenshots/v34/surface-groups-preview.png)。

### 历史确认记录：V33（2026-09-06，已由 V34 替代）

V33 原型的三栏结构保留在 Git 历史中；当前文件的融合方案 A 已更新为 V34，`ui=v33` 旧链接也会打开 V34。以下记录用于追溯原决定。

- 第一栏默认104px，拖动88–160px，折叠后48px；企业和个人入口左对齐，应用图标仍可见。
- 第二栏默认180px，拖动112–360px，双击恢复180px；不因第一栏折叠而消失。
- 外层橙点提示有更新；会话行尾深橙数字，无底色，频道图标与私聊头像保留。
- 工作主区有持续 AI 对话、底部固定输入框与显式上下文；频道内容不会自动变成 Agent Session。

这是静态交互样例：发送/创建/发布、会话历史、通知数量、目录与 Runtime 状态不能视为真实后端能力。
V33 确认仅覆盖桌面信息架构；原生窗口、移动端同等交互和完整无障碍仍需独立验证。
`prototype=private-publish`、`prototype=artifact` 及融合方案B/C保留为历史探索，不是同时生效的产品规范。
详见 [产品需求](../product-requirements.md)、[文档一致性审查](../design/v33-documentation-audit.md)。

### 领域路由（不等于常驻一级导航）

通过 `?screen=<route>` 直接进入页面。频道默认使用 V34；如需历史频道工作台，使用 `?screen=channel&prototype=classic`。显式原型、非频道路由和创建任务弹窗不受默认入口影响：

| Route | 页面 |
| --- | --- |
| `channel` | 频道协作 |
| `inbox` | 个人动态（提及、回复与 Agent 结果） |
| `search` | 全局检索 |
| `tasks` | Agent 任务执行现场 |
| `approvals` | 风险审批 |
| `task-result` | Artifact 接力、详细审查与下一次 Agent 修订 |
| `files` | 文件与产物 |
| `agents` | Agent 目录与权限 |
| `runtime` | Runtime 设备与健康 |
| `sync` | 同步与恢复 |
| `organization` | 工作空间与组织切换 |
| `admin` | 企业管理后台 |

创建任务弹窗使用 `?screen=channel&modal=task`。

V34 左侧菜单试用完整浅灰蓝面板（#EAF0F8），12px 圆角、8px 外侧留白；右侧会话保留白色，统一浅灰窗口底衬托两块区域。明确蓝色仍承载选中与焦点。右侧强调蓝降低饱和度为 #4467B8，Agent 头像使用浅蓝底与深蓝字。此配色待用户确认后通过独立共享 Token 契约同步 Desktop。
