# 私人工作与显式发布：补充验收提案

状态：Proposed / 生产验收 NOT RUN，2026-09-06。
来源：V33 产品评审、[ADR-0005](../adr/0005-private-work-publication-boundary.md)。
不更改 Frozen Scope 1.1 的 AC-001–AC-012 或既有 Gate；纳入交付需 Product/Architecture/Security 评审及重新拆分 Issue。

| ID | 场景与必须证明的结果 | 当前证据 |
| --- | --- | --- |
| PW-01 | Alice不选频道创建私人工作，或只引用有权访问的消息；Bob的频道、搜索、通知和活动列表看不到该工作及其过程 | 静态布局，不构成隔离验证；NOT RUN |
| PW-02 | 发布前选择Artifact版本、说明和目标；取消无共享副作用，仅分享选定内容；Prompt、草稿、路径和工具历史不进入目标 | 早期发布原型仅示意；端到端NOT RUN |
| PW-03 | Bob预览已发布版本、反馈/确认；修订请求回到作者，下一版本关联交付但不暴露私人修订过程 | 独立审查/发布样例；集成NOT RUN |
| PW-04 | 无源分享权、目标权限不足、成员被撤或来源到期时拒绝新增披露；跨频道发布不扩大来源历史访问 | NOT RUN；需密码受众及撤权负向测试 |
| PW-05 | Runtime/模型离线不阻塞IM；私人工作不静默变成共享任务或转给同事；离线发布、重试和去重有明确结果 | NOT RUN；需正式发布契约 |
| PW-06 | 主动创建的共享Task继续按父会话权限观察与审批；UI不把共享Task标成“仅你可见” | 两种原型表面；权限/集成NOT RUN |
| PW-07 | 默认104/180px两栏，第一栏折叠48px、第二栏可至112px且可恢复；外层橙点、内层行尾数字、工作输入固定底部 | V33局部浏览器检查，见handoff；非完整A11Y或真机PASS |
| PW-08 | 明确私人历史的持久化、保留、设备恢复、备份和清除；团队审计不能成为查看私人内容的通道 | 需ADR与契约评审，NOT RUN |

实施顺序：先确定私人历史/发布受众契约，再按客户端、Runtime、Core/Crypto划分任务，最后运行双成员端到端及泄露负向测试。
测试使用合成成员和数据；证据只保存状态、授权结果与不可逆摘要，不能保存真实Prompt、目录内容或凭据。
商业验证另行记录团队交接耗时、重复解释与成果复用，不将UI或功能测试视作付费意愿证据。
